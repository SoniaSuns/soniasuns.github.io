抽样方法与核验边界

从指定来源出发的分层目的抽样

先取得三个 GitHub README 和七个有效会议年份的官方目录，解析候选记录；固定每个 GitHub 主来源 18 篇、每个会议年份主来源 3 篇，再在层内选择不同研究内容。公开检索仅用于补全已选候选的 arXiv ID、标题变体与 venue，不作为另起一套选论文来源。

[推断] 层内选择以覆盖控制形式、编辑、基础生成、长时生成、记忆、交互、几何、后训练、数据、评测及视频推理为目的。这是目的抽样，非随机抽样，也不是完整 systematic review；论文数不能用于估计整个领域占比。每篇只分配一个主抽样来源，多处收录另行保留。
