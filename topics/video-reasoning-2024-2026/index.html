Editing、Control 和几何一致，属于不同分类轴

Video editing 不等同于 video control。生成式 editing 通常是 controllable video synthesis 的一种应用。Control 描述用什么条件约束输出；editing 描述是否修改一个已有视频实例；几何一致描述输出必须满足什么性质。

例子Editing？Control？解释
输入相机轨迹，从一张图生成新视频通常否是没有要求保留某个源视频的既有过程。
重拍原视频，只改变相机路径是是源视频编辑 + 相机控制 + 几何保持。
输入某人的参考照，生成新剧情通常否是身份定制；使用参考不等于编辑参考实例。
让多视角生成符合相同 3D 场景取决于任务取决于输入几何一致本身是目标性质。

你的研究最适合写成：事件 / 状态层面的选择性编辑 + 干预后果推理 + 无关内容保持。它与 Control 相交，但比“让物体沿轨迹运动”多了决定什么必须改变、什么必须保持的推断问题。

统计口径与覆盖限制

严格纳入

R1：论文明确提出推理、规划、任务分解或 plan–generate–verify 过程，并用其指导视频内容、编辑或训练信号。普通 caption 改写、LLM text encoder、causal attention 不自动纳入。

R2：视频生成的状态 / 帧 / rollout 被实际用于推理回答、动作规划或联合视频–轨迹规划。只称“未来可能帮助规划”不纳入；纯 latent RL world model 不属于这里的 Video Gen。

R3：明确评测视频生成器的推理、规则归纳、规划或因果过程能力。用 CoT 评价画质不等于评测生成器的推理能力。

宽口径与不确定项

另列物理一致、干预 / counterfactual、普通 RL / reward / search、推理式质量 evaluator，以及尚不能区分显式推理和一般条件预测的论文。这份候选集用于复核，不应视作“宽口径已确认篇数”。

Video Gen 包括直接生成 / 修改视频、其专用组件、数据、评测，以及确有视频输出的交互世界模型。排除纯理解、检索、普通恢复 / 超分、纯静态 3D 和仅 latent 的规划系统。

所有标签都是本轮判断 [推断]；严格 R 已核对摘要，尚未逐篇读全文。G 是标题与可用摘要粗筛；未抽样审计漏检率，不给置信区间。

来源组处理规则
CVPR / ICCVCVF 主会目录；排除 workshops；标题计数与公开摘要。
ICLR / ICML / NeurIPS / ECCV官方 virtual 目录；按规范化标题、相同 OpenReview forum 合并重复展示；排除 journal-to-conference、blog。NeurIPS 包含 Datasets/Evaluations 与 Position，ICML 包含 Position。

SIGGRAPH / SIGGRAPH Asia / TOGSIGGRAPH 两行仅 conference-paper track；journal track 在 TOG 行体现。TOG 按卷年，不重复加回 SIGGRAPH。此表不能直接解释为 SIGGRAPH 全部 technical papers 的规模。
TPAMI / TOG使用出版商提交给 Crossref 的记录；按卷年，排除未入卷 early access、勘误、编辑性条目。2026 是截至检索日已入卷数据。
MMACM 主论文集的 proceedings-article，包括论文集内短文及挑战赛等；不是仅 regular papers。2026 官方网站与 Crossref 尚未提供本轮能核对的完整篇目，保留 NA。
缺失摘要CVF 单篇页、会议单篇展示页、arXiv 补查；部分 ACM / TPAMI 采用 OpenAlex 按 DOI 索引的摘要。摘要覆盖见逐年表。摘要不足的论文不进入严格 R。

不同 venue 的收录 track 不完全相同，论文总量是这里明确列出的目录口径，不是统一意义的官方 acceptance count。跨 venue 合计按记录计；同一工作的期刊扩展版不据标题强行合并。
